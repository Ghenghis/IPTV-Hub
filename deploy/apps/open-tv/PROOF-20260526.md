# Open TV Provider-Vault Proof — 2026-05-27

Status: `provider-ready`

## What Changed

- Added a tracked `static-web-overrides/` layer for the hosted Angular build.
- Added `hls.js` and a browser player overlay so the hosted app no longer calls
  native Tauri/mpv playback.
- Apollo Group TV and XtremeHD load from DaveTV provider-vault catalogs.
- Live channels and movies use safe same-origin `/api/provider-vault/stream`
  URLs.
- Fixed hosted playback by trusting the vault-provided safe stream URL before
  trying to synthesize a URL from item fields. The previous build rebuilt live
  rows into empty-id stream requests and returned HTTP `400`.
- Interleaved Apollo Group TV and XtremeHD rows so both providers are visible
  and playable at the top of the catalog instead of burying XtremeHD hundreds of
  rows below Apollo.
- The hosted build skips the old "add your first source" Tauri flow when vault
  providers are configured.
- HLS playback uses larger buffers:
  `maxBufferLength=180`, `maxMaxBufferLength=600`, `backBufferLength=90`.
