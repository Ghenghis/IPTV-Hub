# Stalker UI Provider-Vault Proof — 2026-05-26

Status: `provider-ready`

## What changed

- Added a tracked `static-web-overrides/` layer for the live React/Vite
  Stalker UI build used by `apps.daveai.tech/stalker-ui/`.
- Added Apollo Group TV and XtremeHD provider-vault catalog loading for movies,
  series, and live TV.
- Playback URLs now pass through safe same-origin
  `/api/provider-vault/stream` URLs instead of requiring raw provider data.
- Hosted API calls default to same-origin `/api`.
- Live TV now opens on `All Channels` by default so provider channels are
  immediately visible.
- Provider-vault mode returns an empty EPG payload locally instead of hitting
  stale legacy `/api/v2/epg` and producing console errors.
- Added a hosted Samsung/Tizen `webapis` stub and patched the script path to
  `/webapis/webapis.js` so nginx no longer falls back to `index.html` and the
  browser no longer throws `Unexpected token '<'`.
