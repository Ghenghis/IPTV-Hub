# IPTV Restream Provider-Vault Proof — 2026-05-26

Status: `provider-ready`

## What changed

- Added a tracked `overrides/frontend/` layer for the IPTV Restream React/Vite
  frontend.
- Apollo Group TV and XtremeHD now load from DaveTV provider-vault catalogs.
- Playback uses safe same-origin `/api/provider-vault/stream` URLs.
- Provider-vault rows now trust the vault-supplied safe `item.url` first, then
  fall back to the first non-empty provider identifier (`id`, `stream_id`,
  `num`, `epg_channel_id`, or raw Xtream ids). This prevents empty `id=`
  playback requests when Apollo/XtremeHD catalog rows intentionally omit direct
  stream ids from top-level fields.
- Provider artwork is intentionally rendered as local initials badges in this
  app. IPTV Restream's compact horizontal list is now free of broken external
  poster/logo fetches while playback remains provider-backed.
- Upstream demo channels are hidden whenever vault providers are available.
- Provider-vault channels are read-only in this app, avoiding accidental writes
  to IPTV Restream's legacy channel store.
- HLS playback now uses larger buffers for steadier streams:
  `maxBufferLength=180`, `maxMaxBufferLength=600`, `backBufferLength=90`.
