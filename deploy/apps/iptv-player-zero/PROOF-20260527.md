## Provider 19 Repair - 2026-05-27

Follow-up user screenshots showed a real missed case: a fresh/stuck browser
could display the provider panel but still have no imported playlists, because
the quickstart autoload marked the current build as complete before IndexedDB
and `window.Store` were ready. If that happened once, later reloads refused to
retry and the app stayed empty.

Additional fixes:

- Bumped hosted build/cache keys to `20260527-free-provider19`.
- Wait for `window.Store` and the eager IndexedDB open before importing
  provider rows.
- Do not mark provider autoload complete until each provider actually saves
  playable rows.
- If autoload fails, remove the build marker so the next load repairs instead
  of getting stuck.
- Strengthened the free/pro hosted UI polish so the upstream upgrade modal
