## Fix Notes

IPTVnator chooses its playback engine from URL shape. Apollo live streams were originally exposed as raw TS-shaped URLs, which caused the app to choose the wrong engine and fail with media demuxer errors. The v15 fix exposes Apollo live rows as HLS-shaped `ext=m3u8` URLs while the Smart provider-vault service still fetches the real Apollo TS source through `sourceExt=ts` and transcodes to browser-safe H.264/AAC HLS TS segments.

The Smart provider-vault service is deployed from `G:\Github\IPTV-web\Smart-IPTV-Web`; that directory is not a Git repository in this workspace. The deployed VPS bundle is `smart-provider-vault-hls-ext-v15-20260528T141000.tgz`, with a VPS backup at `/opt/davetv/backups/smart-iptv-web-before-hls-ext-v15-20260528T141000.tgz`.
