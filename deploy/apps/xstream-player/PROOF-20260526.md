# xstream-player DaveAI Proof — 2026-05-26

## What changed

- Switched the IPTV-Hub package from the pinned upstream Docker image to a
  DaveAI-maintained source build.
- Mirrored the live VPS source into `deploy/apps/xstream-player/source`.
- Converted the UI from Portuguese-first to English-first.
- Kept DaveAI provider-vault support for Apollo Group TV / XtremeHD style
  Xtream Codes providers.
- Wired the provider-vault login path through playback pages so Apollo Group TV
  and XtremeHD work without exposing credentials to the browser:
  - Login accepts a private `providerId`.
  - Live, movie, and series playback use tokenized `/api/provider-vault/stream`
    URLs when a provider login is active.
  - Manual Xtream login remains available as a fallback.
- Added larger HLS buffering defaults for smoother movie playback:
  - VOD target buffer: 300 seconds.
  - Live target buffer: 90 seconds.
  - VOD memory budget: 512 MB.
  - Live memory budget: 192 MB.
- Replaced the dead external login background image with local CSS visuals.
- Changed optional TMDb/OpenSubtitles config reads from `404` to quiet
  `{ configured: false }` `200` responses when unset.
- Updated the VPS `davetv-xstream-player.service` to run the proper Next.js
  standalone server entrypoint.
