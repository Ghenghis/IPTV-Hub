## Important Boundary

XStream is accepted for separated provider mode. It does not yet have the Zero
Player-style combined tagged provider browser. Combined/tagged browsing, catalog
download buttons, and quality-group filters are the next XStream feature wave.

## Deployment Note

The Next standalone runtime must include `.next/static` inside the nested
standalone tree. Future deploys must preserve:

```bash
rm -rf /opt/davetv/services/xstream-player/.next/standalone/.next/static
mkdir -p /opt/davetv/services/xstream-player/.next/standalone/.next
cp -a /opt/davetv/services/xstream-player/.next/static \
  /opt/davetv/services/xstream-player/.next/standalone/.next/static
```
